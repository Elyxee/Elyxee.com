# Transition material

`Assets/Transitions/combustion-cloud.png` is the local texture used by the opening and the scrolling fire curtain. Generated with the built-in ImageGen tool, using `Assets/background/Fire.jpg` (archived in Git checkpoint `3af42f9`) only as a palette and material reference. The current page uses the unchanged `Assets/background/Fire-clean.png`; the unused source painting was removed from the working folder.

Generation prompt — subject and constraints:

> Create a new full-field turbulent combustion cloud, with realistic fine incandescent filaments and dense rolling smoke. Match the reference’s old Romantic oil-painting texture, stippled grain, burnt sienna, charcoal, copper and old gold. Use irregular dark pockets and varied fire structure throughout the field. No people, rocks, horizon, text, signature, neon blobs or repetitive cartoon flame tongues.

The traveller, cliff geometry, star field, white vapour motion, fire advection, reveal and edge masks are rendered in code. The texture contains no person or landscape.
